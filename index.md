# Control de un UR3 mediante gemelo digital y realidad mixta
{: .fs-9 }

Documentación del proyecto final: selección de hardware, arquitectura, protocolos de comunicación y toma de decisiones para controlar un robot colaborativo UR3 a partir de su gemelo digital en realidad mixta.
{: .fs-6 .fw-300 }

## Sobre este proyecto

Este sitio documenta el desarrollo de un sistema donde un operador utiliza lentes de realidad mixta (Meta Quest 3) para manipular el gemelo digital de un robot UR3, validar trayectorias y ejecutarlas sobre el robot físico — todo integrado con un sistema de inventario inteligente.
